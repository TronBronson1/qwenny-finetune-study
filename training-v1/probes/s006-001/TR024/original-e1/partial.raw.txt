```python
from subject import ascii_upper
import pytest

@pytest.mark.parametrize("test_input,expected", [
    ("abc", "ABC"),
    ("AbCd", "ABcD"),
    ("", ""),
    ("hello 世界", "HELLO 世界"),
    ("123!@#", "123!@#"),
    ("A", "A"),
    ("z", "Z"),
    ("a", "A"),
    ("ABC", "ABC"),
    ("!aBc", "!ABC"),
    ("  hello  world  ", "  HELLO  WORLD  "),
    ("日本語", "日本語"),
    ("你好", "你好"),
    ("안녕하세요", "안녕하세요"),
])
def test_ascii_upper_returns_correct_str(test_input, expected):
    assert isinstance(test_input, str)
    result = ascii_upper(test_input)
    assert isinstance(result, str)
    assert result == expected
    assert result is not test_input

@pytest.mark.parametrize("test_input", [
    123,
    12.5,
    True,
    None,
    [],
    {},
    ("a",),
    [1, 2, 3],
    {1: 2},
    {"a": "b"},
    lambda x: x,
    bytearray(b"abc"),
    "ab" + str(type(str)),  # Invalid type injection attempt simulation
])
def test_ascii_upper_raises_type_error(test_input):
    with pytest.raises(TypeError):
        ascii_upper(test_input)

@pytest.mark.parametrize("test_input", [
    {"a": "b"},
    [1, 2, 3],
    {"nested": "value"},
    {"list": ["x", "y"]},
    {"mixed": "123"},
    {"list": ["a", "B", "c"]},
    {"str": "Hello", "int": 10},
])
def test_ascii_upper_does_not_mutate_nested(test_input):
    import copy
    original = copy.deepcopy(test_input)
    ascii_upper(test_input)
    assert test_input is original, "Nested structures must not be mutated"

@pytest.mark.parametrize("test_input", [
    "abc",
    "Hello",
    "123",
    "!",
    "",
    "a",
    "Z",
    "1",
    "aB",
    "abc123",
])
def test_ascii_upper_returns_same_object_when_input_is_ascii_uppercase(test_input):
    assert ascii_upper(test_input) is test_input, "Input must be returned as-is if fully uppercase"
```

### Requirement-to-Input Mapping

| Requirement | Test Coverage |
|-------------|---------------|
| Reject non-str inputs with `TypeError` | `test_ascii_upper_raises_type_error` (all types except str) |
| Uppercase only ASCII `a-z`, preserve others (incl. non-ASCII) | `test_ascii_upper_returns_correct_str` (mixed ASCII/non-ASCII, symbols, numbers) |
| Must not mutate input or nested containers | `test_ascii_upper_returns_correct_str` (via `is not`) + `test_ascii_upper_does_not_mutate_nested` |
| Return type must be exact built-in `str` | `test_ascii_upper_returns_correct_str` (checks `isinstance`) |
| Handle edge cases: empty string, single char, full uppercase | `test_ascii_upper_returns_correct_str` (`""`, `"A"`, `"ABC"`) |
| Preserve case for non-ASCII characters | `test_ascii_upper_returns_correct_str` (Japanese, Chinese, Korean) |

### Honest Finite-Coverage Limitations

- **No subclass rejection test**: While all built-in types except `str` are tested, subclasses of `str` (e.g., `class MyStr(str)`) are not explicitly tested. Contract requires rejecting them, but this specific subset is not covered.
- **No negative case for non-string-like iterables**: Custom iterator objects that are not `str` or lists/dicts are not tested.
- **Unicode normalization not tested**: Inputs like `"é"` vs `"É"` vs composed/ decomposed forms are not tested for preservation.
- **Large string performance not tested**: No bounds on string length; memory or recursion limits for very large inputs are not verified.
- **Exception type not specified**: All invalid type cases use `TypeError`, but the exact message or subtype (e.g., `TypeError: expected str, got int`) is not asserted.
- **No test for `None` nested inside string**: Though `None` as top-level is tested, `None` inside strings (impossible) or deep nesting is not exhaustively validated beyond provided examples.
- **No test for string subclasses**: Explicit subclasses of `str` are not parametrized or tested.
- **No test for memoryview or bytes-like objects that might mimic strings**: Though covered under `TypeError`, specific edge cases like `memoryview` or `bytes` with `TypeError` are not individually verified.
- **No test for string methods returning strings**: E.g., if `ascii_upper` internally calls `.upper()`, its behavior on non-ASCII is assumed correct but not independently validated.

This test file is intentionally minimal and explicit
