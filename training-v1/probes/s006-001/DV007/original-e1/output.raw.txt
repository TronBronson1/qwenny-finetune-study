### Requirement-to-Input Mapping

1. **Type Validation**: `row`, `column`, `rows`, `columns` must be exact `int` instances (not `bool`). Any other type raises `TypeError`.
2. **Bounds Validation**: `rows` and `columns` must be positive integers. Any value ≤ 0 raises `ValueError`.
3. **Cell Bounds**: `row` must be in `[0, rows)` and `column` must be in `[0, columns)`. Out-of-bounds values raise `IndexError`.
4. **Return Format**: Returns a list of tuples `[(dr, dc), ...]` representing orthogonal neighbors in up, right, down, left order.
