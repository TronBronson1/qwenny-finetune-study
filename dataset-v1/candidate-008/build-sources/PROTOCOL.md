# S010 — CPU-only rubric-gap repair (candidate-008 draft)

Declared November 5, 2026, before building candidate-008. This responds to the independent audit in `independent-review/c007-rubric-audit/`, which found gold/rubric gaps still open in candidate-007.

## Scope

- Build `dataset-v1/candidate-008`: a training/development-only derivative of candidate-007 with 60 training and 12 development tasks.
- Final/regression definitions are never imported or opened.
- Candidate-006 and candidate-007, approved exports, `CURRENT_CANDIDATE.txt`, models and earlier study outputs are preserved.
- There are no optimizer updates, no model generation and no training approval.

## Method

1. **Same generator.** Reuse candidate-007's own builder functions from `studies/S007-measurement-repair/build_repair.py`. Before writing anything, regenerate candidate-007's SPEC, PROMPT, TARGET, gold, cases, reference and mutant files and require byte equality; this is the `--reproduce-007` gate.
2. **Declared additions only.** `repair_config_008.py` lists every added valid and invalid case, keyed to audit findings N1–N6. Expected values come from the separate original oracle and are asserted equal to the unchanged reference inside `build_cases`. Added explicit value errors also receive the generator's automatic type-before-value companion cases.
3. **Mutants.**
   - Every candidate-007 designated mutant is kept with the same id and source, and its witness is refreshed against the revised gold. A lost witness aborts the build.
   - Audit mutants of the families type-ordinary, order, mutation-valid, ascii and boundary that survived candidate-007 are regenerated by the audit's own code. The build requires each to match the source hash recorded in the audit.
   - Such a mutant is promoted to a designated mutant only if candidate-007's `requirement_witness` finds a declared witness in the revised gold. Mutants that survive are listed, not counted.
4. **Deferred.** Error-path input mutation (audit N7) changes the model-visible coverage expectations, so it is deferred to a separately declared prompt revision.

## Calibration gate

- All revised gold suites pass the unchanged references, with non-empty tests and no skips or xfails.
- Every designated mutant fails, and its declared witness node is among the failures.
- The independent audit rerun on candidate-007 → candidate-008 reports zero gaps newly introduced in 008.

Validation here runs on Linux with the available Python and pytest. Validation on the established Python 3.15 / pytest 9.2 Windows runtime remains required before any training use.

## Not in scope

- Tokenizer length profiling with the pinned base. Added cases lengthen the training targets, so profile before training and do not silently raise the token budget.
- Corpus approval or export.
- Rescoring any earlier model outputs.
