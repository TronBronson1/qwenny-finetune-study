# What S009 does and does not establish

The comment intervention remains untested as a paired quality comparison. Both variants were successfully packaged, calibrated, token-masked and exercised through actual backward/generation preflights. Only the fresh calibrated baseline received optimizer updates, and it stopped before E5. The treatment trajectory and all scored task answers were unattempted.

The planned-denominator convention must not turn absence of attempts into evidence of model inability. The machine ledger marks all 24 cells unattempted; completion against the planned denominator is 0/24, while reference validity, strict acceptance and comparative model quality are unmeasured. No E1/E3 substitute or best-of-checkpoints inference is allowed.

The observed runtime shift deserves investigation before another expensive study. Positive and zero-free-memory batch groups differ in input lengths, task order and execution time; the four zero samples are dependent observations, not an experiment isolating memory causality. The unfinished batch has no completed timing record. No usable per-process Windows memory data or source identifying another process is available. Neither shared-memory spill nor an unrelated application is established as the cause.

Next work should separate runtime stability from training quality: use a new prospective diagnostic with explicit sampling, a sustained representative workload and bounded time; record resource availability before and throughout the run; and stop on the existing limits without closing apps. A new paired attempt requires its own run IDs and freeze, with the same verified data and a justified prospective ceiling. Preserve this failed allocation rather than overwriting it or claiming a successful comparison.

Even if a future paired comparison favors comments, this eight-task one-seed visible pool would remain exploratory. A practical adoption claim still needs a strong prompted-base arm, broader frozen development confirmation, uncertainty reporting and reserved regression/final evaluation. This study does not change the historical S006 score or select a deployable Qwenny.
